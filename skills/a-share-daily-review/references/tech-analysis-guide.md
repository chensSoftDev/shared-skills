# 涨停股技术指标分析指南

本指南用于在复盘报告中接入当前环境可用的行情数据，将定性分析与技术指标结合。Kimi CLI 环境优先使用 `query_stock`；Codex、Claude 或其他没有 `query_stock` 的环境，应使用可访问的行情网页、结构化数据源或 API 替代，并标注实际来源。

---

## 1. 何时调用 query_stock 或替代行情源

在以下分析场景中，优先使用 Kimi CLI 的 `query_stock` 补充数据；若当前环境没有该工具，改用可靠替代数据源：

| 分析场景 | Kimi CLI 优先参数 | 无 query_stock 时的替代方式 | 目的 |
|---------|-------------------|--------------------------|------|
| 重点个股 K 线分析 | `type=realtime_price` | 行情网页或结构化分钟 K 线数据 | 验证封板质量（早盘封 vs 尾盘偷袭） |
| 个股技术形态判断 | `type=realtime_tech` | 可靠行情源的 MA/MACD/KDJ/RSI/BOLL 数据；拿不到则标注待核验 | 判断趋势位置和风险信号 |
| 次日早盘观察清单 | `type=realtime_price` | 竞价、分时或开盘后行情源 | 获取竞价和开盘后走势 |
| 大盘情绪判断 | `type=open_summary` 或 `type=close_summary` | 涨停池、指数行情、市场宽度数据 | 获取市场整体情绪 |

**限制与注意事项**：
- `realtime_tech` 仅支持 A 股（.SH/.SZ/.BJ），不支持港股。
- `query_stock` 每次调用最多支持 3 个 ticker，重点分析股超过 3 只时需分批次调用。
- 北交所股票（.BJ）可查询 `realtime_price` 和 `open_summary`/`close_summary`，但 `realtime_tech` 对北交所的支持需以实际返回为准，若返回错误则在报告中标注"技术指标暂不支持北交所标的"。
- 没有 `query_stock` 时，不得写“已调用 query_stock”；必须写实际行情源和采集时间。

## 2. 技术指标在复盘中的应用

### 2.1 MACD（判断动能）

| 状态 | 解读 | 对涨停股的意义 |
|------|------|---------------|
| MACD金叉且红柱放大 | 多头动能增强 | 涨停持续性概率高 |
| MACD死叉或红柱缩小 | 多头动能减弱 | 警惕涨停次日回调 |
| 顶背离（价格新高MACD未新高） | 上涨动能衰竭 | 高位涨停风险大 |
| 底背离（价格新低MACD未新低） | 下跌动能衰竭 | 反弹涨停可靠性高 |

**报告写法示例**：
> "该股当日涨停，但MACD 60分钟级别出现顶背离，次日需警惕放量滞涨。"

### 2.2 KDJ（判断超买超卖）

| KDJ状态 | 解读 | 观察提示 |
|---------|------|---------|
| K、D、J均 > 80 | 严重超买 | 高位延续风险较高，关注回落承接 |
| K、D、J均 < 20 | 严重超卖 | 首板反弹可靠性较高 |
| J值从高位拐头向下 | 短期调整信号 | 观察次日开盘承接 |
| KDJ金叉在低位 | 趋势转强信号 | 结合量能判断持续性 |

**报告写法示例**：
> "该股7天6板后，日线KDJ的J值已达96，处于严重超买区，次日若不能继续加速，分歧概率极大。"

### 2.3 RSI（判断强弱）

| RSI(6) | 状态 |
|--------|------|
| > 80 | 极强，但可能回调 |
| 50-80 | 强势区间 |
| 30-50 | 弱势区间 |
| < 30 | 极弱，可能反弹 |

**应用**：
- RSI > 80 的涨停股：次日高开低走概率增加
- RSI 从30以下反弹至50以上的涨停股：趋势反转可能性高

### 2.4 BOLL（判断位置与波动）

| 位置 | 解读 |
|------|------|
| 股价突破BOLL上轨 | 强势，但可能回归 |
| 股价沿BOLL上轨运行 | 极强趋势 |
| 股价从BOLL中轨反弹涨停 | 趋势健康 |
| 股价跌破BOLL中轨后反弹涨停 | 需确认是否真突破 |

### 2.5 均线系统（判断趋势位置）

| 均线状态 | 趋势判断 |
|---------|---------|
| 股价 > MA5 > MA10 > MA20 > MA60 | 多头排列，强势 |
| 股价突破所有均线且均线粘合 | 变盘信号，可能启动 |
| 股价远离MA5 | 乖离率大，可能回踩 |
| 涨停但受MA60压制 | 长期趋势未转强，谨慎 |

**报告写法示例**：
> "该股今日涨停突破MA60，且MA5/MA10/MA20呈多头排列，技术形态支持趋势延续。"

## 3. 封板质量的技术验证

通过 `query_stock type=realtime_price` 或替代分钟 K 线数据，可以验证封板质量：

| 封板类型 | 分钟K线特征 | 质量评级 |
|---------|-----------|---------|
| 一字板 | 开盘即涨停，无分钟K线下行 | ★★★★★（一致性强，但流动性差） |
| 早盘秒板（9:30-9:45） | 开盘后1-3分钟内直线拉升封死 | ★★★★☆ |
| 盘中换手板（10:00-14:00） | 充分换手后放量封板 | ★★★★☆（资金分歧转一致） |
| 尾盘偷袭板（14:30后） | 尾盘突然拉升封板 | ★★☆☆☆（常为弱势表现） |
| 反复开板 | 封板后多次打开 | ★★☆☆☆（分歧大，次日风险高） |

**报告写法示例**：
> "该股13:11首封，13:58最后封板，期间开板4次，分钟K线显示13:30-13:50存在明显放量分歧，属于典型的分歧转一致换手板。"

## 4. 大盘情绪指标

通过 `query_stock type=close_summary` 或替代收盘摘要数据，补充到"复盘摘要"中：

| 指标 | 来源 | 应用 |
|------|------|------|
| 涨停家数 | close_summary | 判断市场整体热度 |
| 跌停家数 | close_summary | 判断亏钱效应 |
| 涨跌比 | close_summary | 判断普涨/分化 |
| 量能变化 | close_summary | 判断资金活跃度 |

---

## 5. 技术指标与逻辑档位的交叉验证

建议将技术指标作为逻辑档位的辅助验证：

| 逻辑档位 | 技术指标理想状态 | 技术指标警示状态 |
|---------|----------------|----------------|
| 硬逻辑 | 均线多头、MACD红柱、放量突破平台 | 顶背离、严重超买、尾盘偷袭 |
| 中性逻辑 | 趋势转强但位置中等、量能温和 | 位置过高但基本面待验证 |
| 擦边逻辑 | 超跌反弹、技术修复 | 高位加速、无量一字、纯情绪 |

---

## 6. 数据标注规范

在报告中引用技术指标时，使用如下格式。数据来源必须写实际使用的工具或网页，不可把不可用工具写成已调用：

> **技术面**（数据来源：query_stock `realtime_tech` / 行情源名称，查询时间：YYYY-MM-DD HH:mm）
> - MACD：日线级别红柱放大，无顶背离
> - KDJ：J值72，未进入严重超买区
> - RSI(6)：68，强势区间
> - BOLL：股价沿上轨运行，开口扩大
> - 均线：MA5/MA10/MA20多头排列，股价站稳MA5

---

## 7. 风险声明

技术指标基于历史价格计算，具有滞后性。短线交易受情绪、消息面影响极大，技术指标仅作为辅助参考，不能替代基本面分析和逻辑判断。
