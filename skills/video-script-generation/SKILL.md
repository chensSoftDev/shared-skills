# 视频脚本生成

## 角色

为指定主题生成结构化短视频脚本 `script.json`，把选题、叙事大纲、逐场景对白、视觉描述和时长控制整理成视频生产管道可消费的格式。

## 约束

### 叙事角色库

根据主题复杂度和目标时长选择合适场景，不必全部使用。

| role | 叙事功能 | 写作要点 | 必要性 |
|------|----------|----------|--------|
| hook | 开场钩子 | 前 3 秒决定留存。用反常识、数据反差或悬念句式，不用“大家好今天聊...” | 必选 |
| myth | 常见误区 | 指出 1-3 个大众直觉里的错误认知，制造“原来我理解错了”的感觉 | 推荐 |
| root_cause | 底层原因 | 从误区转向真正的可控变量，避免空洞鸡汤 | 推荐 |
| example | 具体例子 | 用日常生活场景解释抽象逻辑，越具体越好 | 推荐 |
| action | 行动方法 | 给出 2-3 个可立即执行的步骤，不给“努力就好”这类空话 | 推荐 |
| caveat | 反转提醒 | 防止观众过度简化，管理预期 | 可选 |
| wrap_up | 收束总结 | 一句话复述核心观点，留下行动号召 | 必选 |

### 场景数量

- 60 秒以内：3-4 个场景，通常是 `hook`、1-2 个中间场景、`wrap_up`。
- 90-120 秒：5-7 个场景，使用更完整结构。
- 用户指定时长时，按比例调整场景数量和每段时长。

### 对白规则

- 每段 `dialogue` 控制在 30-50 字，口语化、短句为主，适合听觉消费。
- 避免书面语，例如“综上所述”“众所周知”。
- 避免连续两个场景用相同句式开头。
- 不编造具体数据或案例，不引用未经核实的信息。
- 总时长控制在目标范围内，默认 90-120 秒，用户可指定。

### 视觉描述规则

- `description` 要具体到画面元素，例如“便签纸上写着三个问号”，不要只写“有趣的画面”。
- `action` 要有动态感，例如“主角把卡片排成三列”，不要只写“展示卡片”。
- 视觉字段直接指导后续素材准备和画面制作。

## 工作流

### 1. 主题研究

- 分析用户关键词，明确目标受众、核心问题和常见误解。
- 如果关键词太宽泛，收窄为 5-8 字、适合做视频标题的主题短语。
- 从认知类、方法类、故事类等角度中选择最有信息增量的切入方式。
- 向用户确认主题短语和切入角度后再继续。

### 2. 搭建大纲

- 按叙事角色库选择场景组合。
- 先列出每个场景的一句话摘要，不写完整对白。
- 展示 7 点以内的大纲，等待用户确认叙事结构。

### 3. 逐场景打磨对白

将大纲展开为完整 `script.json`，每个场景包含：

```json
{
  "scene": 1,
  "role": "hook",
  "title": "开场钩子",
  "description": "场景视觉描述（给素材搜索和画面设计用）",
  "action": "角色/画面动作说明",
  "dialogue": "旁白文案（口语化，30-50字）",
  "duration": 15
}
```

### 4. 质量自检

- 检查每个场景是否有独立信息点，没有重复内容。
- 大声读对白，确认像人在说话而不是在念稿。
- 检查 hook 第一句话是否能留住前 3 秒。
- 检查 action 场景是否具体到用户能马上做。
- 汇总 duration，确认总时长在目标范围内。
- 删除“在当今社会”“其实很简单”等空洞表达。
- 确认 description 和 action 能直接指导素材或画面制作。

### 5. 输出脚本

- 将完整 JSON 数组写入指定路径，通常为 `<outputDir>/script.json`。
- 向用户展示完整脚本，逐场景列出标题和 `dialogue`。
- 用户确认脚本后，后续视频生产管道才能消费该文件。

## 输入

- 主题关键词、目标受众、目标时长、视频语气和输出目录。
- 可选的用户补充观点、案例或禁用表达。

## 输出

- `<outputDir>/script.json`。
- 用户可审阅的逐场景标题、对白、视觉描述和时长摘要。

## 示例

```json
[
  {
    "scene": 1,
    "role": "hook",
    "title": "开场钩子",
    "description": "画面中央一个巨大的问号缓缓碎裂",
    "action": "碎片散落后露出主题文字",
    "dialogue": "你以为努力就能成功？真正卡住很多人的，是一个很少被提到的认知盲区。",
    "duration": 13
  }
]
```

## 自检

- [ ] 主题短语和切入角度已让用户确认。
- [ ] 大纲已让用户确认后才写完整对白。
- [ ] 每段 dialogue 口语化、短句为主，并控制在 30-50 字。
- [ ] 未编造数据、案例或未经核实的信息。
- [ ] description 和 action 具体可执行。
- [ ] 完整脚本已展示给用户确认。
