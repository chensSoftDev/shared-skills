# 持仓体检框架

用于 A 股持仓跟踪中的完整体检、动态止盈止损、资金面判读、个股/ETF 分框架分析和操作参考。普通只读查询可压缩输出；涉及体检快照、资金面、加减仓/止盈止损参考时必须按本文件执行。

## 动态止盈止损参考面

| 模块 | 必须检查 | 输出要求 |
|------|----------|----------|
| 初始纪律线 | 买入时止损/目标、是否已由用户确认 | 未确认必须标注“待确认”，不得当作硬纪律执行 |
| 价格结构 | 成本、前高/前低、平台支撑/压力、日内高低点、缺口 | 给出当前最关键的支撑位、压力位和失效位 |
| 趋势结构 | MA5/MA10/MA20、均线排列、价格与均线乖离 | 区分短线趋势、波段趋势和过热状态 |
| 量能承接 | 成交额、换手、量比、放量/缩量上涨或下跌 | 判断上涨质量、回踩健康度和高位兑现压力 |
| 资金面 | 主力净流入/流出、超大单/大单/中单/小单方向、开盘后资金变化、资金流与价格是否背离 | 输出“主力回流/资金分歧/拉高派发/承接换手/散户接盘/资金未核验”等标签 |
| 题材/板块 | 个股题材强弱、ETF 对应板块/指数相对强弱 | 个股看情绪和题材退潮；ETF 看板块趋势是否仍强 |
| 消息风险 | 公告、监管、业绩、产业新闻、复盘联动 | 未核验不得写成“无风险”，只能写“未检出/待核验” |
| 确认方式 | 盘中触发、收盘确认、次日竞价/开盘确认 | 每条止盈止损参考必须写明触发方式 |

## 资金面判读规则

- 大单/超大单净流入且价格上涨，偏向主动进攻；若同步放量突破关键位，可提高强势延续权重。
- 大单/超大单净流出但价格上涨，标记为资金分歧；若高位冲高回落，优先考虑拉高派发或兑现压力。
- 大单净流出但价格不跌，标记为承接换手；需结合尾盘是否守住关键位，不能直接判断为弱。
- 小单净流入、大单净流出，标记为散户接盘风险；个股短线需降低追高和隔夜预期。
- 开盘大单买入多、随后大单卖出占优，标记为“早盘冲高后资金转兑现”，重点看回落是否放量、尾盘能否收回高位。
- 资金流数据源不一致时，先写明来源差异，再给条件判断；不能把单一 APP 的资金流结论当作确定事实。

资金面数据源与最简路径见 `eastmoney-data.md`。当需要使用东方财富接口获取实时行情、资金流、逐笔成交、分时或日 K 时，先读取该引用文件并按其中字段口径解析。

## 接口失败与降级

- 联网请求失败、空响应、字段缺失、接口限流时，最多重试 2 次；仍失败则在报告中标注“未取到/未核验”，不得把失败写成“无风险”。
- 资金流接口只取到累计净额时，必须用相邻时间点差值计算分钟净流入；不得把累计值直接当作当分钟流入。
- 逐笔成交接口若只覆盖最近窗口，必须写明覆盖区间；不得用最近窗口推断全天大单占比。
- 沿用旧快照中的均线、资金或公告数据时，必须写明旧数据时间和原因；不得冒充本次实时数据。
- 不同数据源结论冲突时，先标注来源差异，再给条件判断。

## 动态风控表

每只标的必须输出动态风控表：

| 字段 | 含义 |
|------|------|
| 初始止损 | 买入时最大风险防线，需用户确认 |
| 动态止损 | 根据支撑、均线、前低、成本线、逻辑证伪点动态上移或收紧 |
| 止盈区间 | 根据压力位、前高、目标价、涨停/冲高回落、量能异常给出分批观察区 |
| 触发方式 | 盘中触发 / 收盘确认 / 次日确认 |
| 不可下移规则 | 除非买入逻辑重估并经用户确认，否则动态止损不得下移 |
| 失效条件 | 什么情况说明原判断错了，进入风控或降低预期 |

动态规则：

- 盈利后若价格有效脱离成本区，动态止损优先上移到成本线、关键均线、前低或平台支撑附近，而不是继续沿用买入时的固定亏损线。
- 达到目标价后，不直接给“卖出”指令；改为输出止盈区间、分批参考、上移观察位和回落失效位。
- 个股短线若出现放量跌破关键位、题材退潮、炸板不回封、次日竞价显著低于预期，可盘中触发风控参考。
- ETF 波段若盘中刺破关键位但收回，应优先标记为“盘中触发，待收盘确认”；只有放量下跌且收盘跌破 MA20/平台下沿/确认止损时，才升级为波段风控。
- 止损下移属于高风险动作：必须说明原买入逻辑是否发生变化、为什么原止损失效、是否需要用户确认；默认不允许下移。

## 个股与 ETF 分框架

**个股短线风控框架（`type=stock`）**

| 模块 | 必须输出 |
|------|----------|
| 状态标签 | 强势延续、冲高兑现、分歧换手、破位风控、弱修复、等待确认 |
| 短线位置 | 相对成本、止损/目标、日内高低点、MA5/MA10/MA20、成交额/换手/量比 |
| 资金面 | 主力净流入/流出、超大单/大单方向、开盘与盘中资金变化、资金流与价格是否背离 |
| 题材与消息 | 所属题材强弱、是否有涨停/断板/炸板/异动公告/监管风险 |
| 操作参考 | 持有观察、止盈/减仓参考、止损/风控参考、不建议加仓、条件加仓 |
| 触发条件 | 涨到哪里进入止盈区，跌破哪里进入风控，次日竞价/开盘看什么 |

**ETF 波段管理框架（`type=etf`）**

| 模块 | 必须输出 |
|------|----------|
| 状态标签 | 趋势延续、趋势修复、震荡回踩、跌破趋势、过热兑现、等待确认 |
| 趋势位置 | 相对成本、MA5/MA10/MA20、近 5/10/20 日高低点、成交额/换手/量比 |
| 板块强弱 | 跟踪方向是否强于指数，是否放量上攻、缩量回踩或高位宽幅震荡 |
| 资金面 | ETF 成交额、量比、资金流/份额变化（若可获取）、与跟踪方向强弱是否一致；ETF 资金流权重低于趋势和板块强弱 |
| 波段参考 | 继续持有观察、分批止盈参考、降低仓位参考、等待回踩、不建议追高 |
| 触发条件 | 站上/跌破哪条均线改变判断，接近目标/止损如何分批处理，盘中刺破是否需收盘确认 |

## 建议标签

必须使用以下标签之一或组合，且写成“参考/观察/若...则...”格式，不能写成确定性买卖指令。

| 标签 | 使用条件 | 输出要求 |
|------|----------|----------|
| 继续持有观察 | 趋势/逻辑未证伪，未触发止损/止盈 | 写明观察位和证伪条件 |
| 止盈/减仓参考 | 进入止盈区间、涨幅过快、冲高回落或高位放量 | 写明分批、等待确认、上移观察位和回落失效位 |
| 止损/风控参考 | 跌破动态止损、逻辑证伪、关键支撑失守 | 写明触发事实、确认方式、风险级别和后续观察 |
| 不建议加仓 | 追高、波动过大、逻辑未确认、已接近目标 | 写明为什么不适合加仓 |
| 条件加仓 | 原逻辑强化、回踩不破、放量突破、仓位允许 | 写明必须满足的前置条件 |
| 待补信息 | 缺少买入逻辑、持仓类型或确认纪律线 | 写明需要用户补充什么 |

## 操作决策参考

**加仓参考**

- 原买入逻辑是否强化：新催化、业绩验证、趋势确认。
- 当前仓位占比是否允许加仓。
- 加仓后成本变化和新止损位建议。
- ETF 只能在趋势确认或回踩不破时讨论条件加仓，追高场景默认提示风险。

**减仓/止盈参考**

- 是否已达目标位或进入动态止盈区。
- 题材/趋势是否有退潮迹象。
- 大单/超大单方向是否从主动买入转为主动卖出。
- 是否出现“小单接盘、大单撤退”或“价格上涨但主力净流出”的背离。
- 个股侧重短线兑现压力；ETF 侧重分批止盈、上移观察位或保留底仓。
- 达到目标后必须给出“止盈区间 + 上移观察位 + 回落失效位”，不能只按盈利百分比判断。

**止损参考**

- 是否已触发预设止损位。
- 买入逻辑是否已证伪。
- 纪律执行 vs 主观判断的权衡。
- ETF 盘中刺破止损但收回时，必须区分“盘中触发”和“收盘确认”。
- 动态止损只能随趋势强化上移或收紧；如需下移，必须写明逻辑重估依据并请求用户确认。

## 完整体检报告模板

每次完整体检报告默认包含：

1. 数据说明：时间、行情来源、公告/新闻来源、复盘联动状态、风险声明。
2. 组合概览：成本、市值、盈亏、风险等级、组合状态、今日优先级排序。
3. 持仓总表：代码、名称、类型、成本、当前价、日涨跌、持仓盈亏、状态标签、建议标签。
4. 动态风控表：每只标的输出初始止损、动态止损、止盈区间、触发方式、不可下移规则和失效条件。
5. 个股短线分析：适用于 `stock`，按“事实 -> 推断 -> 建议参考 -> 触发条件”输出。
6. 资金面观察：每只标的输出大资金方向、资金流与价格是否一致、资金标签、数据来源和未核验项。
7. ETF 波段分析：适用于 `etf`，按“趋势 -> 板块强弱 -> 资金面 -> 波段建议 -> 日内风控”输出。
8. 操作参考矩阵：每只标的给出上行情景、震荡情景、下行情景对应的观察或处理参考。
9. 明日/下一时段观察清单：竞价、开盘、午后、尾盘分别看什么。
10. 缺失信息：买入逻辑、持仓周期、确认止损/目标、仓位上限等。
