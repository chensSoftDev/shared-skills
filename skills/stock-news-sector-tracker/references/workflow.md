# 工作流速查

## 盘前（08:20）

1. 读取配置文件和注册表
2. 扫描隔夜消息：美股、期货、汇率、政策、公司公告
3. 对每个板块判断状态：埋伏/确认/加速/错过/风险/调整
4. 输出盘前简报（次日观察清单）

## 开盘（09:32）

1. 获取竞价结果
2. 确认哪些埋伏机会被资金认可
3. 结合持仓给出提醒
4. 记录异动信号

## 盘中（10:00/11:30/13:10/14:00/14:48）

1. 扫描板块和个股异动
2. 检查持仓止损/止盈条件
3. 对异动板块更新状态
4. 必要时提醒用户

## 盘后（22:00）

1. 全天复盘扫描
2. 生成完整每日扫描报告
3. 对重点机会建立档案
4. 更新注册表（如有新增板块/个股）
5. 提交 git
