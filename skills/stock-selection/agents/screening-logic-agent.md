# 筛选逻辑应用指南（Screening Logic Agent）

本指南帮助Agent理解和执行选股筛选的各个维度的逻辑。

## 核心职责

当用户要求"进行日常全市场筛选"或"基于复盘进行题材筛选"时，本Agent负责：

1. **解析筛选需求** — 理解用户指定的筛选条件和维度
2. **数据采集** — 获取必要的行情和基本面数据
3. **应用筛选逻辑** — 根据指定的维度和条件逐层筛选
4. **风险评估** — 对候选结果进行风险打分和标注
5. **输出结果** — 生成CSV和Markdown报告

## 筛选维度详解

### 技术面筛选

**工作流**：
1. 获取股票的MA(移动平均线)数据：MA5、MA10、MA20、MA60、MA120
2. 获取RSI、MACD、成交量等指标
3. 应用筛选条件（如"股价 > MA20"）
4. 排序和优先级处理

**快速参考**：
```
突破型筛选：价格 > MA20，成交量 > 20日均值×1.5倍
回踩型筛选：距MA60不超过3%，距MA20不低于5%
形态型筛选：双底、杯柄等形态成立
```

### 基本面筛选

**工作流**：
1. 获取最新财报数据：PE、PB、PEG、ROE等
2. 获取行业均值进行相对比较
3. 应用筛选条件（如"PE < 行业均值×70%"）
4. 排序和优先级处理

**快速参考**：
```
低估值筛选：PE < 行业均值×70%，PB < 1.5，PEG < 1
成长型筛选：PEG < 1，ROE > 15%，增速 > 15%
分红筛选：股息率 > 3%，分红稳定
```

### 题材面筛选

**工作流**：
1. 读取复盘报告或从用户指定的题材
2. 构建相关标的池（涉及该题材的企业）
3. 排除已涨停标的（避免追高）
4. 评估题材的强度和持续性
5. 应用筛选条件（如"未涨停"、"基本面无重大缺陷"）

**快速参考**：
```
热点跟踪：板块内涨停股≥3只，目标股相关但未涨停
催化事件：定增、重组、业绩超预期等
资金聚焦：融资融券余额增加、机构增持
```

## 筛选执行步骤

### Step 1: 需求解析

```
用户输入 → 解析维度/条件/范围 → 确认参数
```

**示例**：
```
用户："帮我找技术面突破、估值不高的标的"
解析：
  - 维度：技术面 + 基本面
  - 技术条件：股价 > MA20，成交量放大
  - 基本面条件：PE < 行业均值
  - 范围：全市场
```

### Step 2: 数据采集

```
确定数据需求 → 调用数据API → 数据验证
```

**需要的数据**：
- 沪深京所有股票列表
- 最新行情数据（价格、成交量、涨跌幅）
- 关键技术指标（MA、RSI、MACD）
- 基本面数据（PE、PB、ROE等，最新财报）
- 行业信息和行业均值

### Step 3: 多层筛选

```
初始池 → 过滤1（维度1条件）→ 过滤2（维度2条件）→ 
... → 过滤N（维度N条件） → 最终结果
```

**示例流程**：
```
5000只股票
  ↓ 过滤1（PE < 行业均值）→ 3500只
  ↓ 过滤2（股价 > MA20）→ 2000只
  ↓ 过滤3（成交量 > 20日均值×1.5）→ 800只
  ↓ 过滤4（排除ST/停牌）→ 750只
  ↓ 过滤5（流动性 > 500万元/日）→ 650只
最终：650只候选标的
```

### Step 4: 排序和优先级

```
计算综合评分 → 按评分排序 → 输出TOP结果
```

**评分模型**：
```
综合评分 = 技术强度(权重5) + 基本面(权重3) + 其他(权重2)
```

**排序策略**：
- 低风险标的优先
- 同风险等级内按综合评分排序
- 技术面强度优先（对短线筛选）
- 基本面稳定性优先（对长线筛选）

### Step 5: 风险评估

```
对候选结果逐个评分 → 标注风险等级 → 建议止损/止盈
```

**风险打分**：
```
评分维度：基本面(2分) + 题材(2分) + 技术(2分) + 流动性(1分) + 其他(1分)
总分：0-10分
低风险：1-3分  → ready状态
中风险：4-6分  → conditional状态
高风险：7-10分 → 标记高风险提示
```

### Step 6: 输出报告

```
生成CSV（可导入Excel） → 生成Markdown报告 → 完成
```

**输出文件**：
- `screen-YYYY-MM-DD.csv` - 完整候选清单
- `screen-report-YYYY-MM-DD.md` - 详细分析报告

## 常见筛选模板

### 模板1：短线技术面筛选

```
筛选维度：技术面（主）+ 基本面（辅）
条件：
  - MA排列向上：MA5 > MA10 > MA20 > MA60 > MA120
  - 或股价刚突破关键位：股价 > MA20, 成交量 > 20日均×1.5
  - RSI在30-70区间
  - PE不过分高估：PE < 行业均值×120%
  - 无退市预警/违规记录

输出：按"技术评分 + 成交热度"排序
优化：可按行业分类，优先关注热点行业
```

### 模板2：价值投资筛选

```
筛选维度：基本面（主）+ 技术面（辅）
条件：
  - 低估值：PE < 行业均值×70%，PB < 1.5
  - 高质量：ROE > 15%，盈利增速 > 10%
  - 技术支撑：股价 > MA120（长期趋势向上）
  - 流动性充足：日均成交 > 1000万元

输出：按"PEG值"排序，突出低估+高增长的标的
优化：可引入分红因素（股息率 > 3%）
```

### 模板3：题材驱动筛选

```
筛选维度：题材面（主）+ 基本面（辅）+ 技术面（参考）
条件：
  - 涉及热点题材（从复盘或用户指定）
  - 在该题材相关标的中涨停股 ≥ 3只
  - 目标股未涨停（补涨空间）
  - 基本面无重大缺陷
  - PE相对合理

输出：按"补涨空间 + 基本面评分"排序
优化：可分"产业链"和"概念"两类
```

## 应用技巧

### Tip 1: 多维度综合判断

不要只关注单一维度。技术突破 + 基本面支撑的标的比单纯技术突破的更稳定。

### Tip 2: 数据质量至关重要

确保使用的是最新数据（当天收盘价或实时价）。过时数据导致的筛选结果可信度低。

### Tip 3: 流动性优先

流动性不足的标的难以快速止损，优先过滤掉。

### Tip 4: 循序渐进

从大范围逐步缩小，而不是所有条件同时应用。这样便于理解各个条件的作用。

### Tip 5: 风险评估不可省

即使筛选出了候选，也要进行风险评估。风险等级应该在输出中清晰标注。

## 与其他Agent的协作

### 与逻辑验证Agent的协作

选股Agent输出的候选清单 → 逻辑验证Agent进行深度验证 → 输出逻辑验证报告

### 与复盘Agent的协作

复盘Agent输出涨停池和题材 → 选股Agent基于此进行题材筛选 → 补充回复盘报告

### 与持仓跟踪Agent的协作

选股Agent输出的候选 → 持仓跟踪Agent对比检查 → 提示重复和遗漏

## 常见问题处理

### Q: 筛选结果太多了怎么办？

A: 调整条件，使条件更严苛。或者增加一个"优先级分层"的步骤，输出TOP 50而不是全部。

### Q: 筛选结果太少怎么办？

A: 放宽部分条件，或者转换维度（从技术面转向基本面）。也可以输出"条件接近"的候选作为备选。

### Q: 同一标的在多个维度的评分差异大怎么办？

A: 这正常。可在报告中标注"技术强但估值高"或"基本面强但技术一般"等说明。让用户自己判断。

### Q: 如何处理新股/小股票？

A: 根据用户需求。如果明确要求"不含IPO新股"就过滤掉。流动性不足的小股票也应优先过滤。
