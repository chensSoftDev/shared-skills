## 数据模板说明

### candidates-active.csv - 活跃候选库格式

这是实时维护的候选标的库，记录当前所有活跃候选的最新状态。

**字段说明**：

```csv
代码,名称,发现日期,发现来源,发现维度,当前价,发现价,涨跌幅%,技术评分,基本面评分,风险等级,建议止损位,建议止盈位,逻辑状态,备注
```

**字段详解**：

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 代码 | 字符串 | 股票代码，6位数字 | 600000 |
| 名称 | 字符串 | 股票名称 | 浦发银行 |
| 发现日期 | 日期 | 加入候选库的日期（YYYY-MM-DD） | 2026-06-16 |
| 发现来源 | 字符串 | 来源：daily-screen/review-theme/manual/推荐 | daily-screen |
| 发现维度 | 字符串 | 主要筛选维度：tech/fundamental/theme/risk | tech |
| 当前价 | 浮点数 | 最新收盘价或更新时的价格 | 10.50 |
| 发现价 | 浮点数 | 发现时的价格 | 10.20 |
| 涨跌幅% | 浮点数 | (当前价-发现价)/发现价*100 | 2.94 |
| 技术评分 | 整数 | 技术面评分 1-10 分 | 7 |
| 基本面评分 | 整数 | 基本面评分 1-10 分 | 6 |
| 风险等级 | 字符串 | low/medium/high | medium |
| 建议止损位 | 浮点数 | 建议的止损价位 | 9.80 |
| 建议止盈位 | 浮点数 | 建议的止盈价位 | 11.50 |
| 逻辑状态 | 字符串 | ready/conditional/observing/invalid | ready |
| 备注 | 字符串 | 其他说明信息 | 涉及XX题材 |

**逻辑状态说明**：
- `ready` - 验证完整，可以执行
- `conditional` - 条件满足，有待补充
- `observing` - 观察中，未完全确认
- `invalid` - 逻辑已失效，需转入历史库

**示例数据行**：
```csv
600519,贵州茅台,2026-06-16,daily-screen,fundamental,1850.50,1820.00,1.67,8,9,low,1750.00,2000.00,ready,低估值+高ROE
```

### candidates-history.csv - 历史候选库格式

记录已经完成周期的候选标的（已买入/已卖出/已禁入/已过期）。

**字段说明**：

```csv
代码,名称,发现日期,发现维度,发现价,买入日期,买入价,卖出日期,卖出价,最高价,最低价,最高涨幅%,实现损益%,状态,总结
```

**字段详解**：

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 代码 | 字符串 | 股票代码 | 600000 |
| 名称 | 字符串 | 股票名称 | 浦发银行 |
| 发现日期 | 日期 | 加入候选库的日期 | 2026-06-16 |
| 发现维度 | 字符串 | 初始筛选维度 | tech |
| 发现价 | 浮点数 | 发现时的价格 | 10.20 |
| 买入日期 | 日期 | 实际买入日期（如未买入留空） | 2026-06-17 |
| 买入价 | 浮点数 | 实际买入价格（如未买入留空） | 10.30 |
| 卖出日期 | 日期 | 实际卖出日期（如未卖出留空） | 2026-06-20 |
| 卖出价 | 浮点数 | 实际卖出价格（如未卖出留空） | 10.80 |
| 最高价 | 浮点数 | 持仓期间的最高价 | 11.20 |
| 最低价 | 浮点数 | 持仓期间的最低价 | 10.10 |
| 最高涨幅% | 浮点数 | (最高价-买入价)/买入价*100 | 8.74 |
| 实现损益% | 浮点数 | (卖出价-买入价)/买入价*100 | 4.85 |
| 状态 | 字符串 | sold/expired/invalid/high_risk/禁入 | sold |
| 总结 | 字符串 | 简要总结这次选股的结果和经验 | 成功取得收益，逻辑有效 |

**状态说明**：
- `sold` - 已成交（买入后卖出）
- `expired` - 已过期（超过N天未买入）
- `invalid` - 逻辑失效（初始条件破坏）
- `high_risk` - 风险升级（不再符合风控要求）
- `禁入` - 被禁入（出现硬性禁入条件）

**示例数据行**：
```csv
600519,贵州茅台,2026-06-10,fundamental,1820.00,2026-06-11,1825.00,2026-06-20,1900.00,1920.00,1800.00,5.20,4.11,sold,基本面强，逻辑有效，成功套利
```

## 数据维护建议

1. **日更新**：每日收盘后更新 candidates-active.csv 中的"当前价"和"涨跌幅"字段
2. **周检查**：每周末进行一次完整体检，转移已完成周期的标的到 history 库
3. **备份**：每周备份一份完整的 candidates-active.csv，便于后续回测
4. **数据质量**：定期审查历史库，统计"hit rate"（实际买入的候选比例）和收益情况
