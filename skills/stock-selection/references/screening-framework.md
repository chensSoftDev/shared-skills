# 筛选维度和框架（Screening Framework）

本文档定义了A股选股可用的核心筛选维度、参数范围和快速参考。

## 维度总览

| 维度 | 应用场景 | 核心指标 | 主要参数 |
|------|--------|--------|---------|
| **技术面** | 短线突破、回踩机会、形态反转 | 价格位置、成交量、指标 | 支撑位、压力位、MA、RSI等 |
| **基本面** | 价值发现、成长性投资 | 估值、业绩增速、ROE | PE、PB、PEG、ROE |
| **题材面** | 热点跟踪、催化事件 | 涨停股关联、事件催化、资金聚焦 | 板块、概念、事件强度 |
| **风险面** | 风险规避、禁入标的 | 财务异常、股权风险、流动性 | 违规记录、连续跌停、ST/退市风险 |

## 技术面筛选（Technical）

### 核心应用

**突破型** — 寻找刚突破关键阻力、动能强的标的
- 参数：价格突破某压力位、成交量配合放大、MA排列向上
- 适用场景：短线看好的新高突破机会

**回踩型** — 寻找重点支撑位附近、有反弹潜力的标的
- 参数：价格在关键支撑位±2%、上升趋势中的阶段性回踩、均线支撑
- 适用场景：短线介入的承接机会

**形态型** — 寻找技术形态良好的标的（双底、杯柄等）
- 参数：形态确立、突破颈线、成交量配合
- 适用场景：形态学投资

### 快速筛选条件示例

```
【条件1】突破20日均线上方
- 条件：现价 > MA20，成交量在20日平均成交量 > 1倍
- 结果：初步筛选出上升势头标的

【条件2】股价回踩60日均线（支撑位）
- 条件：距60日均线距离 < 3%，距20日均线距离 > 5%
- 结果：寻找回踩机会

【条件3】技术指标共鸣
- 条件：RSI(14) 20-50区间 + MACD金叉 + 突破某日K支撑
- 结果：多指标确认的突破信号

【条件4】成交量放大
- 条件：当日成交量 > 20日平均成交量的2倍，最好伴随价格突破
- 结果：人气聚焦标的
```

### 技术指标参考

| 指标 | 快速参考 | 筛选应用 |
|------|--------|--------|
| **MA(移动平均线)** | 趋势确认 | 5日/10日金叉、MA排列向上 |
| **RSI** | 动能指标 | RSI < 30(超卖) / > 70(超买)，或底背离 |
| **MACD** | 趋势+动能 | 金叉(看涨) / 死叉(看跌)，或柱状图变化 |
| **成交量** | 人气确认 | 量能突破、温和温量、量价背离 |
| **支撑/压力位** | 关键价位 | 前期高点、前期低点、整数关口 |
| **K线形态** | 反转信号 | 锤子线、吞没线、十字星等 |

## 基本面筛选（Fundamental）

### 核心应用

**价值型** — 寻找低估值、有安全边际的标的
- 参数：PE < 行业均值 × 70%、PB < 1.5、股债收益率差 > 3%
- 适用场景：长期价值投资、配置型

**成长型** — 寻找高增速、有成长空间的标的
- 参数：PEG < 1（PE/增速比小于1）、三年盈利CAGR > 20%
- 适用场景：中长期成长投资

**分红型** — 寻找分红稳定、股息率合理的标的
- 参数：股息率 > 3%、过去3年分红稳定、股利支付率 < 60%
- 适用场景：收益型投资

### 快速筛选条件示例

```
【条件1】低估值成长
- 条件：PE < 20 且 PEG(五年增速) < 1 且 ROE > 15%
- 结果：估值合理的优质成长企业

【条件2】高ROE高增速
- 条件：ROE > 20% 且 营收/净利增速(近3年) > 15%
- 结果：品质优秀的企业

【条件3】相对便宜
- 条件：PE < 沪深300平均PE × 60% 且 市净率 < 2
- 结果：相对大盘低估的标的

【条件4】分红价值
- 条件：股息率 > 3% 且 分红连续3年 > 2元
- 结果：稳定分红的标的
```

### 基本面指标快速参考

| 指标 | 快速参考 | 筛选应用 | 参考值 |
|------|--------|--------|-------|
| **PE(动态)** | 估值相对值 | PE < 行业均值 × 70% | 看行业 |
| **PB** | 净资产估值 | PB < 1.5为低估 | 通常 < 2 |
| **PEG** | 价值/增速比 | PEG < 1为低估 | < 1最佳 |
| **ROE** | 盈利效率 | ROE > 15%为良好 | > 20%优秀 |
| **净利增速** | 盈利增长 | 三年CAGR > 15% | 看增速趋势 |
| **股息率** | 分红收益 | 股息率 > 3% | 通常 > 2% |

## 题材面筛选（Theme-driven）

### 核心应用

**热点跟踪** — 基于涨停股、热点板块发现相关标的
- 参数：涨停股关联的概念/产业链、资金关注度、市场参与度
- 适用场景：复盘后的题材深度筛选

**催化事件** — 寻找有明确事件驱动的标的
- 参数：定增、重组、业绩超预期、政策催化等
- 适用场景：事件驱动投资

**资金聚焦** — 寻找机构/产业资本关注的标的
- 参数：融资融券余额增加、机构持股增加、产业资本进入
- 适用场景：跟踪产业热点

### 快速筛选条件示例

```
【条件1】热点板块内的二三线标的
- 条件：板块内涨停股 > 3只 且 目标股在该板块 且 未涨停 且 基本面无重大缺陷
- 结果：跟风概念的参与机会

【条件2】产业链关联
- 条件：涨停股涉及某催化 → 寻找上下游/同产业链的相关标的
- 结果：产业链联动标的

【条件3】政策催化
- 条件：某政策发布涉及的产业/概念 → 寻找该产业内的优质标的
- 结果：政策受益标的

【条件4】资金关注
- 条件：融资余额环比增加 > 10% 或 机构持股 > 10% 且 近期增持
- 结果：被关注的标的
```

### 题材判断要点

- **强度判断**：涨停股数量、高度一致性、持续性 → 强度越高越值得关注
- **阶段判断**：处于"萌芽/升温/高潮/衰退"哪个阶段 → 影响参与时机
- **参与度**：个股表现是否跟上板块 → 低于板块可能有补涨机会
- **逻辑支撑**：是否有基本面/技术面支撑 → 纯概念题材风险更大

## 风险面筛选（Risk Filtering）

### 核心应用

**禁入规则** — 硬性排除的标的
- 违规被罚、退市预警、连续跌停等

**风险预警** — 需要谨慎对待的标的
- 财务异常、股权风险、流动性风险等

### 硬性禁入条件

```
【禁入1】涉及违规被罚
- 近1年被证监会/交易所通报或处罚（涉及财务/信息披露等）
- 例外：只是轻微罚款且已改正的可观察

【禁入2】退市风险
- ST/退市预警状态，或持续亏损面临退市
- 例外：明确有重组/扭亏预案的可观察

【禁入3】连续跌停
- 近N天连续跌停（≥3个跌停），除非有明确利好破位
- 理由：市场一致看空，未来可能继续跌停

【禁入4】流动性风险
- 日成交额 < 100万元，或换手率 < 0.1%
- 理由：流动性差，难以快速止损

【禁入5】近期已暴跌后反弹
- 近30天内暴跌 > 30%，当前处于反弹阶段但未回到暴跌前
- 理由：可能继续回调，等待更多确认
```

### 风险预警信号

| 信号 | 含义 | 处理方式 |
|------|------|---------|
| **财务异常** | 应收账款异常增长、库存异常积压、现金流恶化 | 标记"观察中"，等待解释或数据改善 |
| **股权风险** | 大股东减持、股权质押比例高、实控人变更 | 根据减持幅度/质押比判断，可能导致停牌 |
| **高估值且无增长** | PE > 100或PEG > 5 | 风险等级升级为"高"，谨慎参与 |
| **产业风险** | 所在产业面临政策压制或产能过剩 | 短期回避，等待产业周期反转 |
| **技术面破位** | 跌破关键支撑位（年线/五年线） | 标记风险升级，暂停追加 |

## 完整筛选模板示例

### 模板A：短线技术面筛选

```
维度：技术面
条件：
  - 股价 > MA20 > MA60 > MA120（MA排列向上）
  - RSI(14) 在 30-70 之间
  - 成交量 > 20日平均 × 1.5倍
  - 无退市预警、无连续跌停
  
适用：短线追高机会
输出：排序按 (现价-MA60)/MA60 升序，优先关注相对靠近MA60的标的
```

### 模板B：题材驱动筛选

```
维度：题材面 + 基本面 + 风险面
条件：
  - 涉及某热点题材/催化（如新能源、芯片等）
  - 在该题材相关标的中涨停股 ≥ 3只
  - 目标股在该题材相关，但未涨停，有补涨潜力
  - PE < 行业均值 或 处于关键技术位支撑
  - 无硬性禁入条件，财务无异常
  
适用：复盘后的题材深度筛选
输出：按热度/补涨潜力排序，标注风险等级和止损位
```

### 模板C：价值发现筛选

```
维度：基本面 + 技术面
条件：
  - PE < 沪深300平均PE × 60%
  - PEG < 1（五年增速）
  - ROE > 15%
  - 股价在 MA120 以上（长期上升趋势）
  - 无风险预警信号
  
适用：中长期价值投资
输出：按 PEG 升序排序，突出低估+成长的标的
```

## 使用指南

### 快速选择筛选维度的方法

1. **如果目标是**：发现短线机会 → 使用**技术面** + **风险面**
2. **如果目标是**：基于复盘发现题材机会 → 使用**题材面** + **基本面** + **风险面**
3. **如果目标是**：发现价值标的 → 使用**基本面** + **技术面**（确认不是下跌中的便宜）
4. **如果目标是**：跟踪热点 → 使用**题材面** + **技术面**

### 参数设置原则

- **保守策略**：条件更严苛，降低候选数量，提高质量
- **均衡策略**：条件适中，平衡数量和质量
- **激进策略**：条件较宽松，增加候选数量，风险相应增加

### 反复迭代和优化

- 筛选出候选后，观察其后续表现
- 记录"预期hit率"（如预计100个候选中有多少成功买入）
- 定期回测和调整条件参数，优化筛选有效性
