# 风险控制指南（Risk Control Guide）

本文档定义了风险等级评分模型、止损建议、风控指标体系，以及如何基于不同买入逻辑类型制定风控策略。

## 风险等级分类

### 三级风险等级定义

| 等级 | 风险评分 | 含义 | 典型特征 | 推荐操作 |
|------|--------|------|--------|--------|
| **低风险** | 1-3分 | 风险因素少，止损明确，收益预期清晰 | 基本面强、技术面支撑明确、题材稳定 | 可正常加入候选库，按计划操作 |
| **中风险** | 4-6分 | 存在一定风险因素，但可控 | 流动性一般、题材不确定性、估值一般 | 可加入候选库但需重点监控，缩小仓位 |
| **高风险** | 7-10分 | 风险因素多或严重，需谨慎应对 | 题材炒作、估值透支、股权风险、产业风险 | 可作为备选观察，暂不操作或极小仓位，止损更严格 |

## 风险评分模型

### 评分维度（总分10分）

| 维度 | 分值 | 评估标准 | 注释 |
|------|------|--------|------|
| **基本面风险** | 2分 | PE、PB、PEG、ROE等是否合理 | PE > 100 或 PEG > 3，加1-2分；财务异常，加2分 |
| **题材/催化风险** | 2分 | 理由的可持续性和确定性 | 纯概念炒作，加1-2分；基本面支撑，0分；政策风险，加2分 |
| **技术面风险** | 2分 | 技术位置、支撑力度等 | 处于压力位被冲击，加1分；缺乏支撑，加2分；支撑明确，0分 |
| **流动性风险** | 1分 | 成交量、换手率是否充足 | 日均成交量 < 500万元，加1分；> 1000万元，0分 |
| **股权/政策风险** | 2分 | 大股东质押、高管变动、产业风险等 | 质押率 > 60%，加1分；产业政策压制风险，加1-2分 |
| **其他风险** | 1分 | 如连续跌停、停牌风险等 | 根据具体情况酌情加分 |

**评分方法**：
1. 逐项评估，每项根据实际情况在"基准分"基础上加分
2. 如无明显风险因素，该项得基准分（0-1分间的低端）
3. 如存在显著风险因素，加1-2分
4. 总分超过7分，升级为"高风险"

### 快速评分示例

**例1：技术突破低估值标的**
```
PE: 15倍（行业均值25）                  → 基本面风险：0分
刚破20日均线，成交量放大                → 题材风险：1分（无催化）
支撑位明确（MA60附近）                  → 技术风险：0分
日均成交 800万元                        → 流动性风险：0分
大股东持股无质押，无异常                → 股权风险：0分
其他：无                               → 其他风险：0分

总分：1分 → **低风险**
```

**例2：热点题材标的**
```
PE: 45倍（高于行业均值）                → 基本面风险：1分
热点题材但政策不确定                    → 题材风险：2分
技术面处于压力位附近                    → 技术风险：1分
日均成交 400万元                        → 流动性风险：1分
大股东质押率 50%                        → 股权风险：0分
其他：无                               → 其他风险：0分

总分：5分 → **中风险**
```

**例3：高估值题材概念**
```
PE: 120倍，PEG: 4.5                    → 基本面风险：2分
纯概念炒作，无基本面支撑                → 题材风险：2分
处于历史高位，缺支撑                    → 技术风险：2分
日均成交 200万元                        → 流动性风险：1分
大股东质押率 70%                        → 股权风险：1分
其他：无                               → 其他风险：0分

总分：8分 → **高风险**
```

## 止损设置指南

### 根据买入逻辑类型设置止损

#### 类型A：技术面突破型

**特征**：基于突破某关键位置（如20日均线、压力位）买入

**止损方式**：技术位止损 + %止损双条件（更严格的先触发）

```
推荐止损设置：
- 技术位：跌破突破点或关键支撑位 ±2%
- 百分比：3-5%（波动率小用3%，波动率大用5%）
- 时间止损（可选）：3个交易日无突破继续走坏，止损

示例：
  买入价：50.00元（刚突破20日均线）
  20日均线支撑：49.50元
  止损位选项：
    方案1（技术位）：跌破49.50元，立即止损
    方案2（%止损）：跌破 50.00 × (1-5%) = 47.50元
    最终止损：min(49.50, 47.50) = 47.50元
```

#### 类型B：基本面低估型

**特征**：基于低估值、好ROE等基本面买入

**止损方式**：%止损 + 技术位双条件

```
推荐止损设置：
- 百分比：5-8%（因为基本面变化不会一天改变）
- 技术位：重要支撑位（如年线、120日均线）
- 财务止损（可选）：业绩恶化、财报爆雷时止损

示例：
  买入价：50.00元（基于PE估值）
  支撑位：年线约 48.00元
  止损位选项：
    方案1（%止损）：50.00 × (1-7%) = 46.50元
    方案2（技术位）：年线 48.00元
    最终止损：min(46.50, 48.00) = 46.50元
  触发：亏损达7% 或 年线破位且成交量放大
```

#### 类型C：题材热点型

**特征**：基于热点题材、涨停股关联买入

**止损方式**：%止损 + 事件/消息止损

```
推荐止损设置：
- 百分比：5-10%（题材波动大，止损可相对宽松）
- 事件止损：题材核心驱动力消失或反转
- 技术位：关键支撑位

示例：
  买入价：50.00元（基于新能源热点）
  核心驱动：政策推动
  止损位选项：
    方案1（%止损）：50.00 × (1-8%) = 46.00元
    方案2（事件止损）：政策反转或负面消息
    最终止损：min(46.00, 事件反转价位)
  触发：亏损达8% 或 题材核心驱动消失
```

#### 类型D：反转/低谷型

**特征**：基于技术反转、政策反转等买入

**止损方式**：严格的%止损（因为反转不确定性大）

```
推荐止损设置：
- 百分比：3-5%（低于其他类型，因为反转未必成功）
- 时间止损：N个交易日未确认反转
- 技术位：新破位点

示例：
  买入价：30.00元（处于多月低位，出现反转信号）
  止损位选项：
    方案1（%止损）：30.00 × (1-4%) = 28.80元
    方案2（时间止损）：5个交易日后仍低于30，止损
    最终止损：min(28.80, 时间检查)
  触发：亏损达4% 或 5个交易日未反转
```

### 止损设置的通用原则

| 原则 | 说明 | 执行建议 |
|------|------|--------|
| **容纳正常波动** | 止损距离应大于股票日常波动范围 | 查询20日平均振幅，止损距离 > 平均振幅 × 1.5 |
| **相对集中** | 避免过大的止损幅度 | 通常 3-10% 为合理范围，极少超过 15% |
| **与买入理由关联** | 止损条件与买入理由应相关 | 因A理由买入，A条件破坏时止损 |
| **执行可行** | 止损必须能够在市场中实际执行 | 避免选择交易稀少的价位作为止损 |
| **事先明确** | 买入前就定好止损，不可事后改口 | 记录在验证报告中，作为承诺 |

## 风控指标体系

### 核心风控指标

#### 1. 估值风险指标

| 指标 | 计算方式 | 低风险 | 中风险 | 高风险 |
|------|--------|-------|-------|--------|
| PE相对值 | 现PE / 行业均值 PE | < 70% | 70%-100% | > 100% |
| PEG | PE / 增速 | < 1 | 1-2 | > 2 |
| PB | 市净率 | < 1.5 | 1.5-3 | > 3 |

#### 2. 财务质量指标

| 指标 | 计算方式 | 低风险 | 中风险 | 高风险 |
|------|--------|-------|-------|--------|
| ROE | 净利润 / 股东权益 | > 20% | 10%-20% | < 10% |
| 毛利率趋势 | 环比/同比变化 | 稳定或上升 | 基本稳定 | 下降 |
| 应收账款增速 | 增速 vs 收入增速 | 低于收入增速 | 接近收入增速 | 远高于收入增速 |

#### 3. 技术面风控指标

| 指标 | 计算方式 | 低风险 | 中风险 | 高风险 |
|------|--------|-------|-------|--------|
| 距关键支撑 | (价格-支撑位)/支撑位 | > 5% | 3%-5% | < 3% |
| RSI | 相对强度指数 | 30-70 | 20-30或70-80 | < 20或> 80 |
| 成交量 | 日均成交额 | > 1000万 | 500-1000万 | < 500万 |

#### 4. 股权和流动性风险

| 指标 | 计算方式 | 低风险 | 中风险 | 高风险 |
|------|--------|-------|-------|--------|
| 大股东质押率 | 质押数量 / 持股数 | < 50% | 50%-70% | > 70% |
| 换手率 | 日均换手率 | > 2% | 0.5%-2% | < 0.5% |
| 流动性评分 | 成交额+换手综合 | 高 | 中 | 低 |

### 综合风控评分表（快速参考）

```
估值风险：
  ☐ PE相对值 > 100% → +1分
  ☐ PEG > 2 → +1分
  ☐ PB > 3 → +1分
  小计：____分

  ☐ ROE < 10% → +1分
  ☐ 毛利率下降 > 5% → +1分
  ☐ 应收账款异常增长 → +1分
  小计：____分

技术风险：
  ☐ 距关键支撑 < 3% → +1分
  ☐ RSI处于极端值 → +1分

  小计：____分

股权/流动性风险：
  ☐ 大股东质押率 > 70% → +1分
  ☐ 换手率 < 0.5% → +1分

```

## 按风险等级的操作建议

### 低风险（1-3分）

**特征**：基本面稳健、技术支撑明确、无重大风险

**操作建议**：
```
仓位：可按正常计划投入（单只 5-10%）
止损：严格执行设定的止损，不扩大
监控：日常监控即可，无需特别关注
加仓：如有额外机会可适度加仓，最大不超20%
减仓：达到止盈目标时逐步减仓
```

### 中风险（4-6分）

**特征**：存在一定风险但可控；或题材不确定但基本面支撑

**操作建议**：
```
仓位：缩小仓位至正常的 50-70%（如正常5%，此时3-3.5%）
止损：严格且更早地执行止损，可缩小至正常的 80%（如原5%，此时4%）
监控：提高监控频率，建议日内检查或隔日不超过1次
加仓：不建议加仓，除非风险因素消除
减仓：更积极地分批减仓，可在 50% 收益时减仓 30-50%
标签：标记为"中风险"，便于后续追踪
```

### 高风险（7-10分）

**特征**：风险因素多、估值透支或题材不确定性大

**操作建议**：
```
仓位：极小仓位（正常的 20-30%，如正常5%，此时1-1.5%）
止损：严格止损，缩小至 3-4%
监控：实时监控，任何负面信号立即评估
加仓：不加仓，除非风险完全消除
减仓：任何反弹都考虑分批减仓，目标 1-2 个交易日内清空或到止损
标签：标记为"高风险"和"备选观察"，不作为主要持仓
处置：如无重大转机，建议于设定期限内（如1-2周）止损或清空
```

## 常见风险情景处理

### 情景1：题材热度下降

**表现**：涨停股数量减少、股票表现落后大盘

**处理步骤**：
1. 评估核心驱动是否仍存在
2. 如驱动消失，立即更新风险等级为"高"
3. 执行止损或逐步减仓
4. 将标的从"活跃候选"转入"历史库"标记为"theme_faded"

### 情景2：突发负面新闻

**表现**：监管风险、业绩爆雷、产业风险等

**处理步骤**：
1. 立即停止加仓
2. 快速评估对买入逻辑的影响程度
3. 如影响严重，立即止损
4. 如影响有限，观察市场反应后再决策
5. 更新风险等级，标记"negative_news"

### 情景3：基本支撑因素改变

**表现**：业绩下修、管理层变化、战略调整等

**处理步骤**：
1. 重新评估基本面和逻辑的有效性
2. 重新计算估值和风险评分
3. 如逻辑失效，止损或观察
4. 更新候选库记录

### 情景4：止损被击穿但后续反弹

**表现**：股价触及止损位后快速反弹

**处理步骤**：
1. 如已执行止损，不追悔（坚持纪律）
2. 如未执行，评估是否因市场情绪波动
3. 若反弹后再度破位，坚决止损
4. 记录此次经验，优化下次止损设置

## 风控检查清单

每次建仓前，完成以下检查：

- ✅ 风险等级评分 ____分，等级为 ☐低 ☐中 ☐高
- ✅ 止损位设置为 ______元（或 ____% ）
- ✅ 建议仓位为 ____% （根据风险等级调整）
- ✅ 是否存在"硬性禁入"因素？ ☐否 ☐是(说明：___)
- ✅ 买入理由与止损条件是否一致？ ☐是 ☐否
- ✅ 最大亏损金额 ____元，是否在承受范围内？ ☐是 ☐否
- ✅ 监控计划已制定？ ☐是 ☐否
- ✅ 是否需要增加风险提示或备注？ ☐是 ☐否（备注：___)
