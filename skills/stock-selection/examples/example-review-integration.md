# 示例2：复盘联动选股工作流

## 场景

用户刚执行完"A股每日复盘"（2026-06-16），复盘结果显示：
- 当日涨停股 28 只
- 新能源汽车/充电桩板块涨停 5 只，是主要热点
- 半导体板块涨停 4 只，但力度不如新能源

用户请求："基于今天的复盘，帮我找新能源板块中有补涨潜力的标的。"

## 执行过程

### 第一步：读取和解析复盘报告

**复盘报告关键信息提取**：

```

     涨停股：300001(特锐德)、002074(国轩高科)、300750(宁德时代)...
     催化：新能源汽车政策支持信号
     
  2. 半导体 - 4 只涨停
     涨停股：688008、603986...
     催化：芯片自主可控话题
     
  3. 医药 - 3 只涨停
     ...

风险评价：
  - 新能源强度：强（5只涨停，持续性好）
  - 半导体强度：中等（4只涨停，有政策支持）
  - 医药强度：弱（3只涨停，缺乏新的催化）
```

### 第二步：主题池扩大化和候选发现

**新能源汽车/充电桩主题的相关标的池**：

```

相关的同主题未涨停标的（扩大化筛选）：
- 产业链上游：锂电池、电池材料
- 产业链中游：充电桩运营、新能源整车
- 产业链下游：电源管理芯片、电机控制等

初步相关标的池：50-100 只
```

### 第三步：多维度筛选

**筛选条件**（自动应用）：

```
维度1：题材关联度
  ✓ 在新能源/充电桩相关行业
  ✓ 最近有题材相关的新闻或业务进展
  
维度2：技术面
  ✓ 未涨停（避免追高）
  ✓ 涨幅 < 5%（补涨空间大）
  ✓ 处于关键技术支撑附近
  
维度3：基本面
  ✓ PE < 行业均值（不过度高估）
  ✓ ROE 合理或有增长预期
  
维度4：风险
  ✓ 无硬性禁入条件
  ✓ 流动性充足
```

**初步筛选结果**：

```
高优先级（推荐关注）：
- 代码1：符合所有条件，补涨潜力大
- 代码2：符合所有条件，基本面强
- 代码3：符合多数条件，流动性一般但可接受
...

中优先级（可观察）：
- 代码A：符合多数条件，但估值稍高
- 代码B：符合多数条件，但流动性一般
...

低优先级（暂不建议）：
- 代码X：虽相关但流动性不足
- 代码Y：估值过高，风险大
...
```

## 关键要点总结

1. **快速启动**：利用复盘报告的热点识别，快速启动题材筛选
2. **产业链思维**：不仅关注涨停股本身，还要追踪产业链上下游的联动机会
3. **补涨逻辑**：选择未涨停但相关的标的，获得补涨机会
4. **风险意识**：题材驱动的选股风险相对较高，需要更严格的风控
5. **数据关联**：复盘和选股报告应相互引用，形成完整的认知链

## 与其他工具的协同

- **与"A股每日复盘"的协同**：利用复盘的热点识别作为输入
- **与"持仓跟踪"的协同**：筛选出的候选不能与当前持仓重复
- **与风控系统的协同**：对题材类候选设置更严格的风控
