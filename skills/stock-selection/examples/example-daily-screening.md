# 示例1：日常全市场筛选工作流

## 场景

用户请求："今天帮我筛一遍全市场，找那些技术突破、估值不高、成交量放大的标的。我想找短线机会。"

## 执行过程

### 第一步：接收和解析筛选需求

**用户输入**：
```
维度：技术面 + 基本面（估值）
条件：
  - 技术：股价突破 20 日均线，成交量 > 20 日平均 × 1.5 倍
  - 基本面：PE < 行业均值 × 100%（不过度高估）
范围：全市场（沪深京）
目标：找 10-30 个优质候选
```

**解析结果**：
- 筛选维度：短线技术面突破 + 基本面估值确认
- 筛选强度：中等（两个维度结合，品质较好）
- 预期数量：20-50 个

### 第二步：数据采集和筛选

**采集数据**：
- 沪深京全市场约 5000 只股票的最新行情
- 20 日均线、成交量数据
- 最新财报数据、行业均值 PE

**筛选流程**：
```
初始池：5000 只 → 
过滤1（股价 > MA20）→ 3000 只 → 
过滤2（成交量 > 20日平均×1.5）→ 1200 只 →
过滤3（PE < 行业均值×100%）→ 520 只 →
过滤4（排除 ST、停牌、异常）→ 480 只 →
初步结果：480 只
```

**初步结果统计**：
```
行业分布：
- 电子：85 只
- 机械设备：72 只
- 电气设备：68 只
- 化工：55 只
- 其他：200 只

风险分布：
- 低风险（PE<行业均值50%）：120 只
- 中风险（PE 50-100%）：280 只
- 高风险（PE>100%）：80 只
```

## 关键细节和注意事项

1. **数据准确性**：确保使用的是当天最新收盘数据（或当前实时数据）
2. **避免遗漏**：初步筛选要覆盖全市场，不要预先排除任何行业
3. **排序公平**：排序公式应客观透明，便于用户理解
4. **风险优先**：即使技术面很好，也要提前警示高风险因素
5. **可追溯**：保存完整的筛选过程记录，便于后续回测
