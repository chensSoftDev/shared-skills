## 🎯 核心设计

### Skill 的五大职责

1. **日常选股筛选** — 从全市场或特定池筛选符合条件的标的
2. **逻辑验证** — 对候选标的进行买入逻辑完整性检查
3. **复盘联动** — 基于复盘的涨停池/题材进行深度筛选
4. **风险评估** — 输出风控指标和止损建议
5. **候选库管理** — 维护候选标的的生命周期

### 五大工作流场景

| 场景 | 触发 | 输出 |
|------|------|------|
| **日常全市场筛选** | 用户指定筛选条件 | CSV + Markdown报告 |
| **复盘联动筛选** | 基于复盘的热点题材 | 题材机会报告 + 候选清单 |
| **逻辑验证** | 用户提交某支股票 | 验证报告 + 风控建议 |
| **风险评估** | 用户查询候选标的 | 风控指标 + 止损建议 |
| **候选库定期体检** | 周末或手动触发 | 体检报告 + 状态转移 |

### 数据流向

```
日常筛选 / 复盘联动 / 手动提交
         ↓
    逻辑验证清单
         ↓
    风控评估
         ↓
candidates-active.csv（事实源）
         ↓
定期体检
         ↓
candidates-history.csv（已完成）
```

## 🔧 使用方式

### 快速开始

1. **执行日常筛选**
   ```
   用户："帮我筛一遍全市场，找技术突破、估值合理的标的"
   → 系统执行筛选 → 输出CSV + 报告 → 可选择加入候选库
   ```

2. **验证候选标的**
   ```
   用户："帮我验证这支股票：代码XXX，理由是..."
   → 系统按验证清单检查 → 输出验证报告 → 通过后加入candidates-active.csv
   ```

3. **复盘后联动选股**
   ```
   执行复盘 → 基于涨停池/题材触发选股 → 输出题材机会报告
   → 相互引用，形成完整认知链
   ```

### 数据操作

- **添加候选**：通过验证后自动写入 candidates-active.csv
- **更新状态**：日常更新"当前价""涨跌幅"，定期更新"逻辑状态"
- **转移记录**：周末体检时将完成周期的标的转移到 candidates-history.csv
