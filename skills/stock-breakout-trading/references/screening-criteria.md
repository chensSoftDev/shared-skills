# 突破选股可量化条件

## 必选条件

| 条件 | 阈值 | 说明 |
|---|---|---|
| 涨幅 | 3% ≤ 涨幅 ≤ 8% | 排除一字板、已涨停和弱波动 |
| 创近期新高 | 收盘价 ≥ 5日高点 × 0.995 | 近似创5日新高，允许0.5%误差 |
| 成交量放大 | 当日成交量 ≥ 5日均量 × 1.5 | 确认资金认可 |
| 量比 | 量比 ≥ 1.5 | 当日交易活跃度 |
| 多头排列 | 收盘价 > MA5，MA5 > MA10 或 MA5拐头向上 | 趋势健康 |
| 上影线控制 | 上影线长度 ≤ 实体长度 × 2 | 避免冲高回落 |
| 流通市值 | 50亿 ≤ 流通市值 ≤ 500亿 | 弹性与流动性平衡 |
| 非ST | 排除ST、*ST、退市整理 | 基本风险过滤 |

## 加分条件

| 条件 | 加分 | 说明 |
|---|---|---|
| 所属板块涨幅 > 2% | +10 | 板块共振 |
| 板块排名前10 | +15 | 强题材驱动 |
| 龙虎榜有机构/知名游资买入 | +10 | 资金背书 |
| 创10日/20日新高 | +10 | 上方压力更小 |
| 成交量创10日最大 | +10 | 资金抢筹明显 |
| PE_TTM < 40 | +10 | 估值合理 |
| 近5日涨幅 10%-30% | +5 | 已有趋势但不过热 |
| 突破前整理时间 ≥ 5个交易日 | +10 | 平台整理充分 |

## 减分/排除条件

| 条件 | 处理 | 说明 |
|---|---|---|
| 涨幅 > 9% | 排除 | 追高，次日低开风险大 |
| 已连板 | 排除 | 等开板看承接 |
| 上影线 > 实体2倍 | 排除 | 假突破信号 |
| 高位放量阴线 | 排除 | 出货信号 |
| 前期涨幅已超50% | 排除 | 高位突破风险大 |
| 大盘科创50跌幅 > 2% | 仓位减半 | 情绪差 |
| 所属板块跌幅 > 1% | 排除 | 无板块配合 |

## 评分公式

```
总分 = 基础满足分（50分）+ 加分项 - 减分项

基础满足分：所有必选条件满足得50分，每少一项扣10分

加分项：按加分条件累计

减分项：大盘差-10，个股前期涨幅过大-15，长上影线-15
```
