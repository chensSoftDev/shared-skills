# 买点 / 止损 / 止盈 / 仓位速查

## 买点

| 买点类型 | 触发条件 | 仓位 | 适用场景 |
|---|---|---|---|
| 确认买点 | 突破当日尾盘14:45-14:55，收盘站稳突破位 | 30-50% | 当日有确定性突破 |
| 回踩买点 | 突破后次日/第三日回踩MA5或突破位，缩量止跌 | 40-60% | 想等更安全位置 |
| 加仓点 | 持仓后继续放量上攻，分时回踩不破均价 | 10-20% | 已有浮盈，趋势确认 |

## 止损

| 触发情况 | 动作 | 幅度 |
|---|---|---|
| 买入次日跌破突破位 | 开盘止损 | 约-3%到-5% |
| 收盘价跌破突破位或MA5 | 无条件减仓/清仓 | 约-5%到-7% |
| 3日内不涨反跌 | 时间止损 | 控制在-7%内 |
| 浮盈5%后回落跌破成本 | 保本出 | 0% |

## 止盈

| 浮盈状态 | 动作 |
|---|---|
| +5% | 止损上移至成本价，保护本金 |
| +10% | 减半仓，留一半博更高 |
| +15%以上 | 再减一半，剩余1/4跟踪止盈 |
| 跌破MA5或日内均价 | 清仓 |

## 仓位

| 场景 | 单票仓位 | 同板块仓位 | 总仓位 |
|---|---|---|---|
| 大盘情绪好 | 15-20% | ≤40% | ≤80% |
| 大盘情绪一般 | 10-15% | ≤30% | ≤60% |
| 大盘大跌 | 5-10% | ≤20% | ≤40% |
| 首次试盘 | 5-10% | - | - |

## 一句话纪律

> 突破买确认，破位即止损；盈利5%保本，10%减半，15%清仓；单票不超20%，同板块不超40%。
