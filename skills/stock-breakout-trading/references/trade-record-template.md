# 突破交易记录模板

## 买入记录

```markdown
# 突破交易买入记录

- **日期**: YYYY-MM-DD
- **时间**: HH:MM
- **标的**: 名称（代码）
- **突破类型**: 平台突破 / 新高突破 / 均线突破 / 缺口突破
- **买入价**: xx.xx 元
- **数量**: xxx 股
- **成交金额**: xxxx.xx 元
- **费用**: xx.xx 元
- **成本价**: xx.xx 元
- **仓位**: x%
- **止损位**: xx.xx 元（约-x%）
- **目标位**: xx.xx 元（约+x%）
- **买入理由**: 放量突破xxx，板块xxx当日涨幅x%，量比x
- **风险**: 次日获利盘抛压 / 板块分化 / 大盘情绪
```

## 卖出记录

```markdown
# 突破交易卖出记录

- **日期**: YYYY-MM-DD
- **时间**: HH:MM
- **标的**: 名称（代码）
- **卖出价**: xx.xx 元
- **数量**: xxx 股
- **卖出类型**: 止损 / 止盈 / 保本 / 时间止损
- **实现盈亏**: +xxx.xx 元（+x%）
- **卖出理由**: 跌破止损位 / 达到目标位 / 板块退潮 / 大盘大跌
```

## CSV字段

| 字段 | 说明 |
|---|---|
| date | 交易日期 |
| time | 交易时间 |
| code | 股票代码 |
| name | 股票名称 |
| action | buy/sell |
| price | 成交价格 |
| quantity | 成交数量 |
| amount | 成交金额 |
| breakout_type | 突破类型 |
| reason | 买入/卖出理由 |
| stop_loss | 止损位 |
| target | 目标位 |
| pnl_pct | 实现盈亏比例（卖出时填写） |
| portfolio_status_after | holding/closed |
