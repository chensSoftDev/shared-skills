# P0/P1/P2 分层矩阵

## 定义

`P0` 是基础卡，用于全 A 覆盖，回答“这家公司是谁、基本干什么、有没有明显风险”。

`P1` 是研究卡，用于横向比较，回答“这只股票有没有研究价值、逻辑硬不硬、主要风险是什么”。

`P2` 是深度卡，用于候选、持仓、主线龙头跟踪，回答“什么情况下关注，什么情况下证伪”。

## 字段矩阵

| 模块 | P0 基础卡 | P1 研究卡 | P2 深度卡 |
|------|-----------|-----------|-----------|
| 元信息 | 必填 | 必填 | 必填 |
| 一句话画像 | 必填 | 必填 | 必填 |
| 基础身份 | 必填 | 必填 | 必填 |
| 主营业务 | 简版 | 完整 | 完整+产业链 |
| 题材概念 | 核心标签 | 相关度判断 | 证伪条件+可比公司 |
| 财务质量 | 简评或待核验 | 核心指标 | 深度解释+异常项 |
| 估值市值 | 简评或待核验 | 必填 | 必填+行业对比 |
| 交易特征 | 不强制 | 简评 | 技术关键位+资金偏好 |
| 重大事件 | 不强制 | 近一年重点事件 | 持续事件流水 |
| 风险标签 | 必填 | 必填 | 必填+处理建议 |
| 研究结论 | 状态标签 | 初步结论 | 多空逻辑+触发/证伪条件 |
| 跨 Skill 关联 | 必填 | 必填 | 必填 |

## P0 必填

- `code`
- `name`
- `exchange`
- `board`
- `industry`
- `knowledge_level=P0`
- `status`
- `last_reviewed`
- `data_as_of`
- 一句话画像
- 主营业务简述
- 企业属性
- 特殊状态
- 核心标签
- 风险等级
- 当前状态：忽略 / 观察 / 禁入 / 待核验
- 数据来源

## P1 增量

- 主营业务拆分
- 收入结构和利润来源
- 题材/概念相关度：硬逻辑 / 中性 / 擦边 / 待核验
- 题材依据：公告 / 财报 / 互动 / 新闻 / 订单
- 财务核心指标：营收、净利润、扣非、毛利率、ROE、经营现金流、资产负债率、商誉
- 估值市值：总市值、流通市值、PE/PB/PS
- 交易特征：成交额、换手、波动、涨停历史
- 风险标签和风险等级
- 初步研究结论：忽略 / 观察 / 候选 / 禁入
- 触发升级到 P2 的条件

## P2 增量

- 多头逻辑
- 空头逻辑
- 核心催化
- 催化兑现路径
- 同题材可比公司
- 产业链上下游
- 重大事件流水
- 技术关键位：支撑、压力、趋势状态
- 资金偏好：游资 / 机构 / 量化 / 趋势资金 / 不明显 / 待核验
- 禁入条件
- 触发重新关注条件
- 逻辑证伪条件
- 下次复核计划
- 与持仓、候选库、每日复盘的具体链接

## 升级规则

- 新持仓：立即升级到 P2。
- 新加入候选库：至少升级到 P1。
- 每日复盘主线龙头：升级到 P1 或 P2。
- 出现重大公告、监管问询、业绩预告、重组、订单、中标：已有卡必须更新事件流水。
- P0 股票连续多次出现在复盘、候选或题材扫描中：升级到 P1。
- P1 股票进入持仓或成为重点候选：升级到 P2。

## 状态规则

不要物理降级，使用 `status` 表示当前有效性：

- `active`：当前仍有研究或跟踪价值。
- `stale`：资料过期，需要复核。
- `archived`：逻辑结束，仅保留历史。
- `forbidden`：禁入或高风险，不建议纳入候选。
